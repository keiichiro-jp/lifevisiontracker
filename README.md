# 企業調査ツール — Company Research Tool

会社名を入力するだけで、その会社の**組織体系・全業務内容・競合企業**を自動調査・リスト化するWebアプリです。  
主な用途：対象企業のAIエージェント構築に向けた情報収集・整理。

---

## 機能一覧

| 機能 | 説明 |
|---|---|
| **企業調査** | 会社名を入力→AIが公式サイト・求人情報・IR資料・プレスリリース・LinkedInを横断調査 |
| **組織体系ツリー** | 部門→部署→役職の階層をインタラクティブなツリーで表示 |
| **全業務一覧** | 担当部署・説明・情報ソース種別（公式/求人/IR/PR等）付きでリスト化 |
| **競合企業 TOP3** | 調査対象と競合する可能性が高い上位3社を自動検出、ワンクリックで即調査 |
| **PDFエクスポート** | 表紙・組織体系・業務一覧・調査ソースを含む整形レポートをダウンロード |
| **調査履歴管理** | 過去の調査結果を左サイドバーに一覧表示、再閲覧・削除が可能 |

## 技術スタック

### フロントエンド
- React 18 + TypeScript
- Wouter（ルーティング）
- TanStack Query（サーバー状態管理）
- Tailwind CSS + shadcn/ui
- jsPDF（PDFエクスポート）

### バックエンド
- Node.js + Express
- OpenAI GPT-4o（企業調査AI）
- Drizzle ORM + PostgreSQL（Neon）
- データベース未接続時はインメモリストレージで動作

## セットアップ

### 必要な環境変数

```env
OPENAI_API_KEY=sk-...        # 必須：企業調査AI
DATABASE_URL=postgresql://...  # 任意：Neon PostgreSQL接続文字列（未設定時はインメモリ動作）
```

### インストール・起動

```bash
npm install
npm run dev        # 開発サーバー起動 → http://localhost:5000
```

### データベースセットアップ（PostgreSQL使用時）

```bash
npm run db:push    # スキーマをDBに反映
```

## 調査ソースについて

AIは以下の情報ソースを参考に調査結果を生成します。

1. **公式コーポレートサイト** — 企業概要・事業内容・組織情報
2. **求人情報** — Indeed・求人ボックス・リクナビNEXT・マイナビ転職・LinkedIn等
3. **IR・決算資料** — 有価証券報告書・決算説明資料
4. **プレスリリース** — ニュースリリース・お知らせ
5. **LinkedIn企業ページ** — 組織・従業員情報
6. **業界ニュース・メディア** — 各種報道

> ※ AIの知識ベースに基づく推論結果です。最新情報は各公式サイトでご確認ください。

## PDFレポートの構成

エクスポートされるPDFには以下のセクションが含まれます。

1. **表紙** — 会社名・調査日・業務数/部門数/競合数サマリー・競合TOP3
2. **組織体系** — 階層構造（インデント表現）
3. **全業務内容一覧** — 番号・業務名・担当部署・説明・ソース種別
4. **調査ソース** — 参照した情報源一覧

## APIエンドポイント

| Method | Path | 説明 |
|---|---|---|
| `POST` | `/api/company-research` | 企業調査を実行・結果を保存 |
| `GET` | `/api/company-research` | 調査履歴一覧を取得 |
| `GET` | `/api/company-research/:id` | 特定の調査結果を取得 |
| `DELETE` | `/api/company-research/:id` | 調査結果を削除 |
